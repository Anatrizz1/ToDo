# 📝 Full Stack To-Do List

Uma aplicação moderna e minimalista de gerenciamento de tarefas, marcando a evolução de um projeto Front-end clássico para uma arquitetura Full Stack com banco de dados real na nuvem.

## 🚀 Funcionalidades
- **Autenticação de Usuários:** Sistema completo de Login e Cadastro (Sign Up / Sign In) protegido.
- **Privacidade de Dados:** Cada usuário tem acesso exclusivo apenas às suas próprias tarefas salvas no banco.
- **CRUD Completo:** Criação, leitura, atualização de status (concluído/pendente) e exclusão de tarefas em tempo real.
- **Layout Dinâmico:** Design responsivo com tela dividida (Split Screen) para autenticação, transitando suavemente para um layout centralizado após o login.

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Back-end / Banco de Dados:** Supabase (PostgreSQL)
- **Autenticação:** Supabase Auth
